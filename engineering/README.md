# Engineering

This directory contains Aiki's durable engineering record and development support material.
It is not part of the language/runtime surface.

- `ai/` — working method for AI-assisted engineering.
- `proposals/` — bounded design contracts organized by disposition.
- `profiling/` — reusable profiling workloads and retained profiling witnesses.
- `evidence/` — optional retained evidence when a result has independent value beyond its proposal.
- `git-hooks/` — repository Git-hook scripts installed by `make hooks`.
- `session-history.md` — cumulative durable execution history.
- `audit-findings.md` — repository-wide engineering findings ledger.
- `runtime-optimization-results.md` — retained cross-project implementation evidence/results.

Current language, runtime, contributor, and user documentation remains under `docs/`.
Executable correctness surfaces remain under `test/` and `selfhost/`.
