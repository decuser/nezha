# Engineering Proposals

Nezha engineering proposals are kept under disposition directories so their status is visible from the tree structure.

Current dispositions:

```text
active      proposals guiding current or near-term work
completed   proposals whose planned work has been completed
superseded  proposals replaced by later decisions
parked      proposals intentionally deferred
```

A proposal belongs in exactly one disposition directory. Move it when its status changes rather than leaving status ambiguous in the filename alone.
